# CardStorming

A collaborative workspace for card-based brainstorming and ideation.

## Getting Started

### Prerequisites
- Node.js installed on your system

### Installation

1. Install dependencies:
```bash
npm install
```

### Running the Server

#### Option 1: Using npm
```bash
npm start
```

#### Option 2: Using the batch file (Windows)
```bash
start.bat
```

The server will start on `http://localhost:3000`

### Stopping the Server

- Press `Ctrl+C` in the terminal where the server is running
- Or use the stop script: `stop.bat`
